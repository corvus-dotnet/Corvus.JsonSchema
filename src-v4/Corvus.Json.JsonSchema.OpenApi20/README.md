# Corvus.Json.JsonSchema.OpenApi20

Object models representing JSON Schema documents (OpenAPI 2.0 / Swagger variant).

The model is generated from the official Swagger 2.0 metaschema
(`id: http://swagger.io/v2/schema.json#`, JSON Schema draft-04), committed verbatim
as `OpenApi20.json` from the OpenAPI-Specification repository's
`_archive_/schemas/v2.0/schema.json`. Regenerate with `src-v4/generatetypes.ps1`.
