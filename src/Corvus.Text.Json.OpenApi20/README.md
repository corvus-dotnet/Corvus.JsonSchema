# Corvus.Text.Json.OpenApi20

Strongly-typed V5 model types for OpenAPI 2.0 (Swagger) specifications, generated from
the official Swagger 2.0 JSON Schema metaschema (`id: http://swagger.io/v2/schema.json#`,
JSON Schema draft-04, committed verbatim as `OpenApi20.json` from the
OpenAPI-Specification repository's `_archive_/schemas/v2.0/schema.json`) using the
Corvus.Text.Json source generator.
